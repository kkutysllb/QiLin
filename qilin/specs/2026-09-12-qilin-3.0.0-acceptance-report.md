## 3. 已证为环境限制的失败

本机外层沙箱阻止 dsh 内部的 macOS Seatbelt 沙箱，报错为 sandbox-exec: sandbox_apply: Operation not permitted。
受影响用例需要真实 bash 工具或内部沙箱，因此无法在本机完成。

已用「原始基线提交的独立 worktree 复跑」证明与本次重构无关：

- Web 回放 replay-round-trip：基线与本树失败数一致。
- 交付物 present：基线与本树失败数一致（1 文件 / 2 项）。

未证归因：引擎回放的 3 项失败（bash-tool、persistent-tools、session-sandbox-root），用例名均指向沙箱或原生插件，但未重跑基线对比。

## 4. 明确未完成、需要产品决策的部分

这些不属于本次重构目标，但属于 QiLin 3.0.0 的产品完整性：

- 品牌美术字：侧边栏与 hero 仍需 QiLin 字标 SVG；当前 hero 显示 dsh 的鲸鱼标记与标语。
- 品牌文案：首页标语仍为探索未至之境；首启声明仍为 DeepSeek Harness 内测声明。
- 渠道重写（S3）：8 个渠道中 7 个有可用 TS SDK；微信无官方个人号机器人 API，属高风险项。
- 能力缺口（S4）：scheduler、mcp、memory、RBAC、guardrails 需要产品侧取舍。
- 主分支切换：按约定在验收通过后进行；本机 e2e 全量无法通过，切换决定权在用户。

## 5. 复现方式

本地验收需要把 DSH_HOME 指向工作区内目录（默认 home 在工作区外会被文件沙箱拒绝）：

    DSH_HOME="$PWD/.qilin-home" pnpm dsh qilin --no-open --port 3090

基线对比方法：

    git worktree add .worktrees/baseline 3083f37c3f
    cd .worktrees/baseline && pnpm install --frozen-lockfile && pnpm run build
    DSH_SNAPSHOT=replay pnpm exec vitest run --config vitest.web.config.ts <目标用例>
