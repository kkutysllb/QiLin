# QiLin Desktop 0.1.1

基于 **QiLin 3.1.3** 的桌面版本：引擎跨过上游 npm 作用域改名线，并集中落地 v0.1.0 之后的真机反馈修复。

## 引擎（3.1.1 → 3.1.3）

- **作用域改名**：上游 `@qilin/*` → `@qilin-agent/*`（v3.1.2 落地、v3.1.3 收尾）。闭包按新名重新封盘（commit `d61554c8a2`），封盘 sha256 随包校验。
- **profile 迁移**：旧版本写进 profile manifest 的 `@qilin/*` 条目在新闭包里已不存在，而宿主只追加新名、不清旧名——装配解析必败会进「崩溃-重启循环」（升级首启实测卡在「正在恢复」）。壳侧在启动宿主前剔除 legacy 条目（幂等，删除前备份 `.pre-migration`），0.1.0 用户升级首启不再踩这个坑。
- **历史会话列表修复**：Electron 内置 Node 没有 Web Scheduler API（Chromium 129+ / Node 25+ 才提供），引擎会话列表的协作式让路路径在数据量越过 work slice 时会以 `scheduler is not defined` 炸掉整个 RPC，侧栏历史会话随之清空。宿主入口补齐 `globalThis.scheduler.yield`（setImmediate 语义，宿主自带时不覆盖）——实测 `session/list` 正常返回 151 条、侧栏历史会话完整。

## 桌面产品面（v0.1.0 后真机反馈）

- **无痕 UI**：激活引擎原生 darwin 形态（KStock 同款）——折叠侧栏整列归零、会话头补回侧栏开关与新会话、52px 顶拖拽带，红绿灯叠在其光学线上。
- **侧栏分区 + 折叠**：面板按「通用 / 扩展」分区（第三方插件行归「扩展」尾部区），表头可折叠、状态本地记忆；面板页（插件管理 / 自动化任务…）补固定兜底条，折叠侧栏后开关与新会话不再消失。
- **红绿灯对齐**：`frame: false` 下 `trafficLightPosition` 根本不生效（实测真因），darwin 改走 `titleBarStyle: 'hidden'` 并配 `{x: 13, y: 19}`，中心落在 26px 光学线上。
- **Dock 点击 / Cmd+Tab 切回只聚焦不重载**：保留用户停留页面——设置页等现场不再被拽回工作区。
- **「关于 QiLin Desktop」改壳自绘**：macOS 原生面板的图标取自 `.app` bundle（`AboutPanelOptions.iconPath` 仅 linux/win32），dev 形态只能是 Electron 默认图标；自绘面板显示麒麟印章 + 版本 + 版权，焦点离开即收起。
- **托盘**：「检查更新…」常驻菜单（打包态走 electron-updater；开发形态点击给出说明，不再无反应），关于项指向自绘面板。
- **设置页**：左轨「返回工作区」下移 10px，让开窗顶红绿灯灯带。
- **侧栏「新会话」hover**：不再比默认暗一档（darwin 下底色与默认同值）；hover 时不再裁掉标签末字（上游 mask 在居中标签上会吃掉末字），改用宽度上限保证长文案压不到右侧 `⌘ N`。

## 安装

1. 下载 `QiLin-Desktop-0.1.1-arm64.dmg`（Apple Silicon）；
2. 拖入「应用程序」；
3. 0.1.0 用户可直接经应用内自动更新升级（blockmap 增量下载）。

## 校验

- 产物门禁 V1–V7 全绿：安装包 / 更新元数据 / 交叉引用 / 闭包 sha256 / dmg 结构 / 版本一致（根 = 打包域 = latest-mac.yml）/ 闭包冒烟。
- 引擎闭包：QiLin 3.1.3 @ `d61554c8a2`，品牌补丁三枚随封盘应用（设置页让位、侧栏分区与 hover、共享主题品牌）。

## 已知限制

- 仅 macOS Apple Silicon（`upstream/qilin.lock.json` target: mac-arm64）；Intel / Windows 待后续。
- 打包体积与 0.1.0 同量级（内含完整引擎运行时闭包）。
