# Agent Note: QiLin 品牌界面与唯一的 Settings 入口

Status: implemented

[English](2026-09-13-qilin-brand-surfaces-and-settings-entry-point.md) | 中文

## Problem

QiLin Web GUI 在呈现自身品牌时有六处缺陷。

产品名旁的版本胶囊从不出现，且有两个互不相关的原因。该胶囊以绝对定位挂在印章标记的 24px 盒子上并带负向顶部偏移，而品牌按钮会裁剪溢出内容，于是胶囊被它所悬挂的那一行切掉；同时，正在运行的 GUI 所服务的产物是在缺少构建环境注入的情况下产出的，`process.env.QILIN_CLIENT_VERSION` 因此被编译为 `undefined`，胶囊自身的守卫什么也不渲染。只修复其中任一原因，仍然得不到一个可用的胶囊。

侧边栏页脚的账号控件是一个贴住栏右边缘的裸 32px 图标。它不携带它所打开账号的任何身份信息，而这种对齐让它读起来像一个走失的图标，而不是页脚自己的账号行。

侧边栏页脚承载了两个 Settings 入口。账号菜单拥有一个 Settings 行，而 [ui-settings-general](../../../../packages/client/ui-settings-general/README.zh.md) 在它下方又画了一个固定在底部的触发行——这个入口正是[账号与落地页迁移](../feature/2026-09-12-qilin-local-accounts-and-landing.zh.md)已经移入账号菜单的那一个。同一个面板有两个入口是组合残留，不是功能。

两套配色都把侧边栏解析为品牌色偏：深色下是 `#0e1a16`，在中性近黑的中心区旁读起来是深绿色；浅色下是 `#f1f7f4`，在白色表面上读起来是浅绿色。

设置页的导航栏固定为 188px。主窗口的侧边栏有指针拖拽手柄，设置导航栏却没有，因此导航标签较长的读者无法把它加宽。

运行中的轮次状态行以厂商蓝做流光，文案为 `深度求索中...` / `Deep diving...`。该标签命名的是模型厂商而不是它所属的产品，其蓝色既不符合印章，也不符合品牌的任何其他部分。

## Decision

**版本胶囊是它所命名文字标的一个行内上标。** [SidebarRoot.tsx](../../../../packages/client/ui-sidebar/src/client/SidebarRoot.tsx) 把胶囊渲染为 `.brandName` 内 `sidebar.brand.name` 占位者的兄弟节点，[SidebarRoot.module.css](../../../../packages/client/ui-sidebar/src/client/SidebarRoot.module.css) 在该 flex 行内给它 `align-self: flex-start` 与 1px 顶部偏移。它不持有任何绝对定位，因此品牌按钮的 `overflow: hidden` 无从裁剪。胶囊显示裸版本号，并把完整的 `version[-commit][-dirty]` 串保留为提示文字。

**胶囊读取的构建元数据属于完整构建。** `pnpm run build` 从仓库解析公开客户端环境（`QILIN_CLIENT_VERSION` 取自 `package.json`、短提交号，以及脏标记），并交给每个打包阶段，因此完整构建会把它内联，胶囊随之渲染。绕过 [build.ts](../../../../scripts/build.ts) 的包级打包调用不嵌入任何元数据，因而不渲染胶囊是正确的；此时不完整的是产物，而不是胶囊坏了。

**账号控件是页脚自己的账号行。** [AccountMenu.tsx](../../../../packages/client/ui-account/src/client/AccountMenu.tsx) 渲染一整行：一个携带已登录地址首字母的 22px 头像，其后是地址本身，两者都处在该行自己的 hover 盒内。展开行由它所显示的账号命名，因此语音控制可以用可见文字寻址它；在没有已知身份时，该行回退到本地化的账号标签，头像回退到用户字形。收起轨道保留一个只放头像的 36px 圆形控件，并以该标签命名。

**账号菜单是唯一的 Settings 入口。** [ui-settings-general](../../../../packages/client/ui-settings-general/src/client/index.ts) 不再声明 `settings.trigger` 子 slot，也不再注册触发内容；[chrome.tsx](../../../../packages/client/ui-settings-general/src/client/chrome.tsx) 只保留面板标题与关闭标签。`sidebar.settings` 仍挂载面板与连接恢复行，因此该席位作为面板的挂载点保留下来，而可见入口随账号走。外壳只在面板关闭时、且只在展开栏中渲染该恢复行，因为收起轨道没有容纳它的空间。

**侧边栏是各套配色中的中性表面。** `--dsw-specific-sidebar-fill` 在浅色下解析为 `#ffffff`、在深色下解析为 `#0f0f0f`——与平台自身浅色与深色侧边栏填充所用相同的中性值——因此这一栏读起来与中心区属于同一表面家族，而不是一块带色偏的面板。品牌色仍由印章、强调色 token 以及状态标签承载。

**设置导航栏可由指针调整宽度。** `SettingsPanel` 把导航栏初始设为 188px，并在其右边缘渲染一个纵向的 `role="separator"`。该手柄捕获指针，提交以拖拽起点为基准、经 rAF 节流的绝对宽度，并限制在 160–360px；可访问名称来自 `settings` 语言命名空间。宽度是占位者自身的查看状态，因此面板卸载即重置，且从不进入设置文档。

**运行中的轮次标签带上产品品牌与印章朱砂。** `chat.deepDiving` 文案在两种语言下都读作 `QiLin...`，`.turnStatus` 用 `--dsw-specific-brand-seal-fill` 给它上色，取代原先的渐变文字裁剪流光；样式表连同其关键帧一起删除了该流光。

**印章颜色是一个主题 token，其来源是印章本身。** [tokens.ts](../../../../packages/client/ui-theme-brand/src/client/tokens.ts) 在 QiLin 覆盖层中新增 `--dsw-specific-brand-seal-fill`。它的两个取值都是 [Seal.tsx](../../../../packages/client/ui-brand/src/client/Seal.tsx) 中印章主体渐变的色标——浅色表面用中间色标，深色表面用受光的顶部色标，且各自在其渲染表面上都达到 4.5:1。印章保留自己的字面量，因为它是品牌印记而非主题化图标；一个规程读取该来源，以证明 token 仍然与之保持一致。

## Alternatives considered

**继续让胶囊绝对定位，只把承载它的盒子加宽。** 溢出的是胶囊本身；加宽印章标记或文字标并不会移动那个持有 `overflow: hidden` 的按钮的裁剪边界。行内胶囊既没有可被裁剪的负偏移，也没有会被遮住的字形。

**加宽品牌按钮，让绝对定位的胶囊不再被裁剪。** 裁剪是把胶囊放到行外的症状；按钮的 `overflow: hidden` 用于在收起交叉淡出期间约束文字标，它不是缺陷。

**保留裸图标，只把它移到左边缘。** 对齐只是抱怨的一半；另一半是这个控件没有指明任何账号。一行显示地址的做法还免去了展开栏中的提示文字。

**让胶囊在缺少构建环境时回退到占位版本号。** 一个报告产物并不携带的版本号的胶囊比没有胶囊更糟：它会打印一个未必与浏览器实际运行的字节相符的仓库版本。构建记录与 `verify-client-build-record` 已经把缺少元数据的产物视为不完整。

**在账号行旁保留一个 Settings 按钮。** 它与账号菜单自己的那一行重复，而且一旦其中之一长出分区深链，两者立刻不一致。入口只有一个所有者，打开路径才能保持唯一。

**把侧边栏的品牌色偏保留为区分度。** 品牌色由印章、强调色 token，以及现在的状态标签与头像承载；侧边栏是一块大表面，其职责是后退，中性填充做到了，色偏没有。

**把设置导航栏宽度放进声明的 store 或设置文档。** 导航栏宽度是一个已挂载面板的查看状态：它既不跨重载、也不跨分区切换存活，且没有其他入口读取它。声明的 store 会比它所描述的面板活得更久，而设置文档属于宿主拥有的持久偏好。

**用指针的绝对 `clientX` 推导导航栏宽度。** 导航栏的原点随窗口移动，因此在窗口缩放之后开始的拖拽会跳变。该手柄改为提交以起点为基准的相对宽度。

**在 chat 样式表中硬编码印章朱砂。** 字面颜色属于 token 层，而状态标签必须在印章变化时跟随印章。token 还能让两种配色模式各取同一条渐变的不同色标。

**保留流光，只改文字。** 流光的渐变是厂商蓝；需求是让标签使用印章的颜色，而"与印章同色"的直白含义就是实心填充。

## Consequences

跳过 `build.ts` 的构建现在会明显地缺少版本胶囊，这使不完整产物的状态在产品中可见，而不是悄无声息。GUI 仍然服务最后一次构建出的产物，因此胶囊只在一次完整的 `pnpm run build` 之后出现。

`settings.trigger` 已从设置 slot 映射、外壳的子声明以及生成的客户端 slot 目录中移除，因此贡献触发内容的包会在加载时报错，而不是渲染进一个无人绘制的席位。slot 映射、外壳规程、apply 规程、chrome 规程、侧边栏 README、设置相关 README，以及子系统 slot 树都随之更新。

设置导航栏的宽度不被持久化：把它加宽的读者会在面板关闭时失去该宽度。这是把宽度挡在设置文档之外所换来的有意取舍；持久偏好需要宿主拥有的字段以及它自己的设置行。

`--dsw-specific-brand-seal-fill` 仅存在于覆盖层：平台配色并未定义它，因此未挂载 `ui-theme-brand` 的打包会让运行中轮次标签继承其周围标签颜色。`qilin` profile 会挂载品牌打包，因此出货的 GUI 能解析该 token。

覆盖：侧边栏套件钉住胶囊作为文字标行的行内 flex 子项，并更新两张展开栏快照；账号套件钉住展开行的账号名与头像首字母、无身份时的回退、收起轨道的纯图标形态及其可访问名称，以及页脚行自身的几何；品牌 token 套件对照印章来源钉住两个印章取值，并断言两种中性侧边栏填充；settings-root 套件钉住不存在第二个 Settings 按钮、打开通道，以及一次把导航栏从 188px 拖到 248px 的指针调整手势；chat 套件钉住 `QiLin...` 文案与状态 token，Web 回放固件携带新标签。
