# NMO 产品理念

[English](nmo.md) | 中文

NMO 是以 QiLin 为锚的产品线宪法：QiLin harness 本身与运行其上的每个产品都遵循它。新产品在开发功能之前先写明如何遵循三条原则；设计争议以三条仲裁；违背任一条的功能不发布。本页是理念的唯一家——产品引用本页，不各自转述。

版本 1.0。修订升版本号并记录缘由；产品实例不私分文本。

## 三条原则

| 原则 | 卡住什么 | 一票仲裁的问题 |
|---|---|---|
| Native（事实原生） | 事实外流到第三方服务或用户记忆 | 「这条事实的真相存在哪？」答案必须是自己的运行时。 |
| Minimal（操作极简） | 系统的事被推回给用户，变成表单、选择与流程 | 「用户要做几步？」系统能推断的不许问。 |
| Open（开放扩展） | 能力长成黑盒 | 「契约公开吗？」没有公开契约的能力不能成为依赖。 |

一句话：Native 保证「你拥有」；Minimal 保证「用户只花任务允许的最少操作」；Open 保证「世界进得来」。

## native

Agent、会话、领域与插件的生命周期及运行时事实由产品自己的运行时原生管理，绝不寄存于第三方服务、外部工具或用户记忆。

承诺：每条产品事实——会话、领域实体、插件状态、配置项——都能以自己的运行时或存储回答「真相在哪」；任意会话可从本地日志完整重建；卸载或迁移不留无法解释的残骸。

非承诺：不承诺自带全部后端（可以调用第三方 API，但调用记录与产生的状态归自己）；不承诺离线可用。

违背 Native 的设计：产品依赖「离开产品后就找不到」的状态，或关键事实只存在于用户脑中或截图里。

验收：任取十条产品事实，每条都能指出落盘位置与重建路径；杀进程后重启，会话与领域状态经日志重建零丢失。

## minimal

用户以任务允许的最少操作完成任务。自然语言是主操作面；系统与 agent 负责推断、匹配与执行；打断只发生在不可逆、高成本或诚信关键的决策点。

承诺：全新安装不读文档、不填配置即到达第一个成果；系统把任务匹配到模式、工具与技能，而不向用户暴露选择器；每次打断都对应一个真实的用户决策，绝无空转的「继续吗」；内部词汇——预设、工作区、会话、插件机制——不进入用户词汇表。

非承诺：不承诺功能少——Minimal 约束交互成本，不约束功能范围；不承诺全自动——确认门是 Minimal 的一部分，不是对它的违背。

违背 Minimal 的设计：让用户做系统本可推断的选择；用多步流程堆叠一句话能完成的事；第一屏是配置页。

验收：每个产品登记 N——标准任务的用户输入次数上限——与 M——首启到首个成果、途中不经过任何配置的步数上限；每个打断点都能回答「用户在这里决策了什么」，答不出的即是缺陷。

## open

官方、第三方与用户的能力都经公开契约扩展产品；能力由契约定义，不由实现定义。

承诺：扩展的发现、注册与调用契约公开，第三方不读产品源码即可接入；同一契约下官方实现可被第三方实现替换；安装的扩展被自动发现与调用，不改产品核心。

非承诺：不承诺未经审核的信任（高危扩展仍走权限与批准面）；不承诺兼容一切历史契约（契约本身版本化）。

违背 Open 的设计：能力必须读完源码才能接入；内置实现与外部实现对同一件事说两套协议；第三方扩展需要手工接线才会被发现。

验收：新增第三方能力不改产品代码、不读产品源码即可落地；移除任一官方插件，产品核心功能完好。

## 使用与修订

新产品立项时写一节 NMO 对账：如何遵循每条原则、在哪里有意让步。让步显式登记——谁让步、为什么、何时收回。本页修订升版本号并记录缘由。
## QiLin 对账

QiLin 是这些产品的引擎基座，因此本节记录引擎侧对账；逐项账目、证据与打断点清单在[改造计划](../plans/2026-10-11-nmo-transformation-plan.md)。

**Native。** Session 日志是每个模型可见事实的唯一记录，格式代次与迁移路径都在本仓（`packages/session/`）；`verify-persistence-formats`、`verify-persistence-catalog` 与 `verify-persistence-changes` 守住这些引用。

**Minimal。** 两个出厂预设覆盖产品的模式：`standard` 是部署默认并呈现原生工具 schema，`ptc` 经生成的 SDK 呈现同一批工具并附带运行时创作能力。进程级工具呈现兜底与默认预设一致，因此未配置的部署与它出货的组合行为一致；客户端的选择器只在新任务上二选一，而不暴露配置面。`apps/web/tests/first-run-metric.e2e.ts` 在隔离的全新 home 上量到：首屏无对话框、未打开任何配置面、编辑器可用前只有 1 个阻断决策（连接工作区）；连同发消息本身共 2 步，对照目标 2。同一路径的文案由 `composer-placeholder` 与 `startup-auto-selection` 覆盖。默认权限预设（`workspace-write`）同样无需用户选择。

**Open。** 插件经公开契约从仓外接入而不改产品代码；移除官方插件后会话照常运行（`apps/web/tests/third-party-plugin.e2e.ts`、`apps/web/tests/shipped-composition.e2e.ts`）。

**登记让步。** 按会话选择工具呈现仍是上游工作，登记在 `QILIN_TOOLS_MODE` 缝上；`shipped-composition` 的 child 编排一例与 `steering` 车道登记为既有红。
