# Session V2 persistence format

English | [中文](v2.zh.md)

## Summary

Inspect the V2 persistence types captured at `qilin-v0.1.3-alpha.2`. Assistant streams are embedded in message or attempt events, and the physical header requires `isSeeded` instead of storing `seedLength`. This snapshot retains V2 declarations before the V3 system-message and envelope changes.

## Source evidence

<a id="characteristics"></a>
## Format characteristics

These facts describe the selected checkpoint. The generated tables below preserve the exact field types and optionality.

- `SessionHeader.version` resolves to the literal 2. Both logical and physical headers require `isSeeded`; the physical header has no `seedLength`.
- `assistant/chunk` is absent. Both `assistant/message.data` and log-only `assistant/attempt.data` require an embedded `stream`.
- Surface replacement declarations retain `start` / `end`; system prompt text remains in `request/header.data.header.system`. The V3 `system/message` event is absent.

The [V2 codec](../../../packages/session/session-format-v1-to-v2/src/codec.ts) owns one-event-per-row framing, range-encoded source references, and inherited cuts derived from `session/end-seed` markers. The [V2-to-V3 specification](../../../packages/session/session-format-v2-to-v3/README.md#v2-to-v3-specification) owns system-message insertion, PTC event names, and canonical envelope conversion.

For a seeded V2 Session, the last `session/end-seed` event carrying `data.inherited: true` identifies the inherited cut by its sequence position. Physical `sourceEventSeqs` may use encoded ranges; the logical schemas retain expanded number arrays.

<a id="verification"></a>
## Verification and limitations

The [source-only extractor](../../../scripts/persistence-schema.ts) ran with TypeScript 6.0.3. Reconstruction omits redundant `object` intersection members and discards normalization-unreachable type definitions; it preserves existing `any` / `unknown` and does not substitute opaque types for unresolved imports. V0 and V2 root digests match the corresponding complete states reconstructed from the prerelease archive.

Historical surface-event declarations permit optional `surfaceOp`. This is retained evidence of declared types, not permission to omit fields required by a codec or migration validator. Opaque values, external plugin events, packed body encoding, and runtime relationships are outside the type inventory’s coverage.

```sh
pnpm run verify-persistence-formats
```

The check validates every format through the current writer, schema completeness, bilingual declarations, and generated tables using only this checkout. It does not replay historical applications or establish migration safety. See the [format index](README.md) for maintenance rules and the [current catalog](../../persistence-catalog.md) for today’s declarations.
