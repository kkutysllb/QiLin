# QiLin Desktop 0.1.0

OpenKylin 首个公开发布版本：基于 QiLin 3.1.1 构建的**原生中文桌面产品**——不是浏览器套壳，而是自有 Electron 壳 + 引擎宿主子进程 + 特权协议承载的完整桌面形态。

## 形态

- **引擎宿主子进程**：程序化 boot QiLin 产品面（cordis 同进程装配，不经 CLI 子进程），loopback 随机/记忆端口，壳退出时优雅关停绝不留孤儿。
- **特权协议承载**：Web client 经 `qilin-app://` 直读 + 认证反代，认证 cookie 全程只存在于主进程（renderer 的 `document.cookie` 恒空）。
- **账号会话跨启动存活**：稳定记忆端口 + cookie 罐持久化（0600 按端口键控回灌）——登录一次，重启免登。
- **自动更新**：electron-updater 读 GitHub Releases（blockmap 增量下载），后台静默下载、确认后安装（安装前自动停引擎）。
- **签名公证**：macOS codesign + notarization（安装即开箱可用，无 Gatekeeper 拦截）。

## 桌面产品面

- 中文品牌启动页（失败恢复三入口：重试 / 禁用插件并重启 / 复制诊断）。
- 自绘标题栏：混排面包屑基线对齐、右侧边栏开关、编辑器/终端直启、工作区 Finder 打开。
- 中文系统菜单 + Dock 图标（麒麟印章）+ 菜单栏托盘（镂空三维斜体 QL）。
- 崩溃报告落盘（`crash-reports/`，滚动 10 份）+ 出厂插件面恢复。
- 插件管理页与上游完全一致（含「可选技能」dsh-skills-bundle 1.1.0 交叠式开关）。

## 引擎基线

QiLin 3.1.1（tag 第四次重发，commit `d9dc36d49912`），锁定于 `upstream/qilin.lock.json`，品牌补丁两枚（印章视觉 + 标题栏 inset），引擎闭包 sha256 封盘随包校验。

## 安装

1. 下载 `QiLin-Desktop-0.1.0-arm64.dmg`（Apple Silicon）；
2. 拖入「应用程序」；
3. 首次启动：签名+公证版本直接打开；后续版本经应用内自动更新。

## 已知限制

- 首版仅 macOS Apple Silicon（`upstream/qilin.lock.json` target: mac-arm64）；Intel/Windows 待后续。
- 打包体积 ~594MB（内含完整引擎运行时闭包），瘦身待后续迭代。
