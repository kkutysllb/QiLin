# UI 刷新与产品补强计划

- 日期：2026-11-13 · 基线：会话格式 v7 与 retry 对齐落地之后的当前工作树
- 依据裁决：D16 视觉方向、D17 目标形态、D18 回归方式、D19 功能优先级（见 [自主路线底稿](2026-11-13-own-roadmap.md)）

## 0. 执行原则

1. **人工前后对比是唯一视觉证据**：不引入截图 golden 门；每批产出固定视口的 before/after 截图组，由人审。
2. **样式迁移按包推进，并加静态棘轮**：每迁一个包，就在 `scripts/` 的 CSS 审计里把它标记为「已迁移」，此后该包新增的字面量颜色/间距/字号直接红，防止回退（这是机器可判定的部分，与截图无关）。
3. **每批收口条件**：`pnpm run test:gui` 全绿、`pnpm run doc-sync` 全绿、`tsc -b` 两套 face 干净、涉及样式的包有对应 README/子系统页更新。
4. **不追求一次全量替换**：先三面（聊天、会话壳、设置），再按使用频次铺开。

## 1. 视觉规格 v1（V0 的产出，先定值再动组件）

### 1.1 强调色（更强，且实测对比度）

| 角色 | 亮色 | 对比度（纸底 `#FAF8F3`） | 暗色 | 对比度（暗底 `#17150F`） |
|---|---|---|---|---|
| accent | `#2563EB` | 4.87:1（AA 正文） | `#7C9BFF` | 6.74:1 |
| accent-hover | `#1D4ED8` | 6.31:1 | `#9DB4FF` | 8.78:1 |
| accent-tint bg | `rgba(37,99,235,.10)` | — | `rgba(124,155,255,.16)` | — |
| accent-ring | `rgba(37,99,235,.35)` | — | `rgba(124,155,255,.40)` | — |

现状 `#4176E6`（`deepseek-500`）在纸底仅 3.99:1，低于 AA 正文；新强调色提高一档饱和度即达标。保留纸感底色（`neutral-bluish-50`）作为身份，不动。

### 1.2 刻度

- **间距** `--qilin-space-0..9`：2 / 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64（沿用设计平台原有的 4/8/12 三档并补齐其余档位；scale 只在 base.css 定义一次）。
- **圆角**（加大一档）：2xs 2 / xs 4 / sm 6 / md 10 / lg 14 / xl 18 / panel 20 / pill 999。
- **字号** `--qilin-text-xs..2xl`：11 / 12 / 13 / 14 / 16 / 18 / 22；行高 1.5 / 1.6 / 1.75。
- **密度**：compact / standard / comfortable 三档，调节字号增量、行内间距与控件高度（复用现有 `--qilin-content-font-delta-*`）。

### 1.3 图标集

- 新体系：24×24 网格、1.5px 描边、圆角端点与连接、内容留白 2px；`currentColor` 着色，尺寸由 props 决定。
- 落点 `ui-primitives/src/icons/v2/`，与现有 16px 图标并存；按界面迁移，迁完一面才移除旧图标。
- 先画 24 个高频图标（发送/停止/重试/附件/模型/设置/搜索/侧栏/文件/分支/工作区/团队…），其余按需补。

### 1.4 布局与断点

| 档位 | 宽度 | 壳行为 |
|---|---|---|
| wide | ≥1280 | 左侧栏 + 会话 + 右栏三栏常驻 |
| medium | 1024–1279 | 右栏变覆盖层，左栏保持 |
| compact | 768–1023 | 左栏收成图标轨（hover/点击展开为浮层），右栏全屏覆盖 |
| narrow | <768 | 单列：左栏与右栏都变抽屉；编辑器/表格横向滚动；输入区全宽 |

新增 `--qilin-bp-*` 断点令牌与布局宽度令牌（侧栏 264/72、右栏 360、会话列最大 820、内容留白 16/24）；替换现有 6 个零散断点。

## 4. 人工证据链约定

- 截图存 `.artifacts/ui-refresh/<批次>/`（gitignored，不污染仓库），命名 `<界面>-<视口>-<before|after>.png`。
- 每批在 §2 证据列的路径下留一份 `index.md`（界面、视口、观察点、结论），作为人工 review 的入口。
- 对比复核清单：对比度（正文 ≥4.5、大字号/控件 ≥3）、间距节奏、圆角一致性、图标视觉重量、窄屏无溢出。

## 5. 风险与取舍

- **图标重画成本**：198 个旧图标不可能一次重画。策略是「新面用新集」，旧面在迁移时随批替换，避免全局停摆。
- **响应式改造面广**：先按「壳 + 会话 + 设置」验证 1.4 的断点行为，再推广；避免一次性动 77 个包。
- **人工对比不可回归**：靠静态审计棘轮兜底，截图只做人审；这是 D18 的已知代价，接受。
- **办公与编码双线**：V5/V6 并行会拉扯同一个核心（工具与面板），建议 V5 先做 Forge/Worktree（与编码主线强相关），V6 随后接 Office 只读面。
