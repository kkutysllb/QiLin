# V6 通用办公：Office 原生工具与文档预览闭环

日期：2026-11-14
状态：计划（拆解完成，待执行）
触发：`plans/2026-11-13-ui-program.md` 的 V6 批次——Office 原生工具（只读解析先行）、文档预览闭环。

## 1. 盘点结论（开工前已核实）

| 层 | 现状 | 结论 |
|---|---|---|
| 预览闭环 | `ui-sidebar-documentpreview/office` 已把 Office 文档经 Host 转换（`office-to-pdf`：LibreOffice 原生引擎 + Node WASM 兜底，DOC/DOCX/XLS/XLSX/PPT/PPTX）后用既有 PDF 正文渲染；含渲染缓存、字号缺失提示（`FontNotice`）、按 Session 文件授权读取 | **预览闭环基本存在**，V6 只做收口与一致性，不重写 |
| 转换服务 | `document/office-to-pdf`：队列、错误分类、缺失字体名、远程面 | 已有，接受 OOXML 缺失字体上报 |
| 模型面 | `skill/skill-office` 只注册**技能**（`office`、`office-docx`、`office-pptx`、`office-xlsx`、`office-render`、`office-recalculate`、`office-export-pdf`）及其脚本资源 | **没有原生只读工具**：模型要读 Office 内容目前只能跑外部脚本，这正是 V6 的缺口 |
| 测试 | `bundle/web-app/tests/document-preview.spec.ts`（配置与授权隔离）、`document-conversion.e2e.ts`（真实转换） | 闭环有覆盖，缺「原生工具读出的内容与预览同源」的用例 |

## 2. 决定

1. **只读先行**：V6 只做读取（文本、表格、幻灯片结构），不做写入/改格式；写入仍走 `ui-sidebar-documentpreview` 与外部工具。
2. **原生工具而非技能**：新增 harness 原生工具（typed schema），不依赖外部 `python`/`libreoffice` 才能读；解析器放独立 Host 包，预览与工具**共用同一份解析结果**，避免两套解读。
3. **上限与安全**：解析在 Host 侧、在 Session 工作区文件授权之内进行；包内 zip 读取设总量/单文件/条目数上限并拒绝实体扩展（zip bomb / XXE）；超大表格与幻灯片分页返回。

## 3. 切片

| 片 | 内容 | 验收 |
|---|---|---|
| **S1 解析内核** | 新建 `packages/document/office-read`：DOCX（正文段落、标题层级、表格）、XLSX（工作表、维度、单元格值与公式文本、合并区域）、PPTX（幻灯片尺寸、文本框与表格）只读解析；纯 JS（zip + XML），不启动进程 | 固定夹具（小/大/恶意 zip/缺关系文件）全部可解析或按错误码拒绝；上限触发有测试；无 `any`，JSDoc 完成 |
| **S2 原生工具** | 注册工具（名如 `office_read`）：参数 `{ path, format?, page?, range? }`，返回带分页的结构化摘要；错误码统一（`unsupported`、`too-large`、`not-a-package`、`path-invalid`）；接入 Session 文件授权 | 工具 schema/描述/错误在快照里固定；越权路径被拒；分页与截断有测试；模型可见文本不含 UI 词汇 |
| **S3 预览一致性** | 预览的 `office` 行走同一解析器的**元数据**（标题层级、工作表清单、幻灯片数）用于缓存键与失败文案；缺失字体仍由转换侧上报 | 同一文件「预览元数据」与「工具摘要」一致（一条 bundle 测试）；缓存键随内容变化失效 |
| **S4 文档与收口** | `office-read` README（中英 + Model Experience + 限制）、`docs/subsystems/` 页、`skill-office` 与预览 README 交叉引用、计划/账本 | `test:docs` 全绿；`verify-package-*` 全绿 |

## 4. 门禁

`pnpm run test:gui`（客户端面）、`npx tsc -b tsconfig.host.json`、`npx tsc -b tsconfig.client.json`、`pnpm run build`、`pnpm run test:docs`、`pnpm run verify-package-meta`、`pnpm run verify-package-dependencies`、`pnpm run verify-package-readme-*`、`pnpm run verify-translation-pairing --write`（改 README 后）、`pnpm run doc-sync`。

## 5. 风险

- **格式漂移**：DOCX/XLSX/PPTX 细节繁多，V6 只承诺「正文、表格、幻灯片文本与结构」，其余（批注、修订、图表、嵌入对象、条件格式）明确列为不支持并进 README 限制。
- **zip 安全**：自带 zip 读取必须限条目数、解压总量与压缩比，拒绝 `..` 路径与外部实体；夹具覆盖恶意包。
- **与转换路径分叉**：预览用 LibreOffice/WASM 转 PDF，工具用解析器读结构——两者对「有多少页/多少行」可能不同，文档要写明各自口径，不要假装同源计数。
- **字体**：解析器不渲染，字体缺失只影响预览转换面，工具摘要不含字体信息。
