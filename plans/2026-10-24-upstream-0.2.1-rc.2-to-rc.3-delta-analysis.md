## 5. 自研内置插件逐项分析

- **skills 族**（`packages/skill/*` + `ui-skill` + `ui-settings-skills`）：rc.3 无代码变更；仅 manifest 版本号。**升级点：无。**
- **MCP 族**（`packages/mcp/*` + `ui-settings-mcp`）：同上，**升级点：无。**
- **侧栏族**（`ui-sidebar`、`ui-sidebar-right`）：上游新增 panellist/guide 的 `.actions` 槽与 pin 模块；QiLin 侧栏为自研重写（QiLin 有 §6 标题栏等本地差异），落点见 §7 表。
- **会话族**（`ui-conversation`）：上游把 View 折叠进 More + 草稿复用；QiLin 有 chat-transcript 等本地改造（见 2026-10-20 计划），需三方对位。

- **设置族**（`ui-settings-general`）：开发者工具开关成功态埋点 `code_work_view_toggle`。
- **工作区族**（`ui-workspace`）：导航语义与 `whenDraftExists`。
- **扩展族**（`extensions/kylin-client-runner`、`extensions/tool-kylin`）：客户端目录再生 + 1 文件埋点/契约跟随。

## 6. 第三方与非内置插件启动分诊

rc.3 对插件面只有**增量**：三个新 list 槽 + 注入字段扩展，无删除、无改名、无既有槽 owner 收窄。

| 变更 | 既有第三方插件影响 | 判定 |
|---|---|---|
| 三新槽 `sidebar.panellist.actions` / `conversation.session.header.views.actions` / `sidebar.right.tab.guide.actions` | 不注册则无 More 菜单；已注册的 `sidebar.panellist`/`conversation.view`/`sidebar.right.tab.guide` 条目会自动进入 More 列表 | **全部可启动**；新增可选能力 |
| `SidebarRootInjected` / `ConversationSessionHeaderInjected` 增量字段 | 结构化类型扩展（additive） | **无需 shim** |
| 客户端目录（runner catalogs）再生 | 插件详情面板的槽清单/API 文档数据 | 无运行时影响 |
| `pluginNavigation.openList()` | 新服务方法 | additive |

**结论：无需要兼容 shim 的启动破缺点。**

## 8. 优先级建议、品牌红线、待拍板项

**建议顺序**：先内核后端（`/models` 列表，独立可测）→ 再客户端契约与 pin（三包 + primitives）→ 再新包与组合接线 → 再草稿语义 → 再埋点 → 最后目录再生/文档/快照/六维审计。

**红线（本批开工前自查）**：
1. 品牌：新包与三槽文案走 QiLin locale 词典（`verify-client-ui-i18n`），不得直出上游英文/中文品牌串；QI 品牌名不得出现 `DeepSeek` 账号栈文案。
2. 账号栈：`llm-deepseek-account` 不引入；`/models` 机制只在 QiLin 的 `llm-deepseek` + `llm-deepseek-api-key` 落地。
3. vendor：rc.3 无 vendor 变更，保持冻结。
4. 会话格式：无 `SESSION_FORMAT_VERSION` 变更；`whenDraftExists` 是客户端导航语义，不落持久化类型变更。
5. QiLin 本地特性不回退：settings 自绘标题栏/麒麟印章、chat-transcript 改造、桌面埋点事件。
6. 取材源固定 `dsh-v0.2.1-rc.3` tag，**不得取 master 漂移内容**。
