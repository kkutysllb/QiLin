## 9. 第三方/非内置插件启动分诊（铁律 4）

QiLin 兼容面：`packages/util/dsh-compat`（aliases/manifest）+ home-paths 的 upstream-named 导出（两笔兼容补丁）。逐破坏性变更分诊（域3/8 回填）：

- **engines.dsh 门**（plugin-engines-dsh）：requirements 改名在场（plugin-compatibility.ts:13、types.ts:17、failure.ts:28），但**有意不采 engines.dsh 优先门**（仅 peerDependencies 判定；operations.ts:158 自述「QiLin enforces the peers」）——QiLin 版本线无法满足 dsh 插件 engines.dsh: ^0.2.x，采门会拒装全部 dsh 插件；engines 保持 advisory。dsh 第三方插件安装不被 CLI 前置拒绝，不兼容由安装后加载拒绝 + `qilin plugin allow-version` 豁免承担。
- **experimental-package-composition**：五个 hook/webhook 包不入模板/OPTIONAL_BUNDLES ✓；只 enable 已移除行的 patch 不再插件的语义由 patch.ts implied()/组合实现承载。
- **subagent-activations / plugin-install-over-installed / plugin-option-placement / tool-presentation-mode / subpath-plugin-display-manifest / remove-runtime-invariants**：已对齐（见 §1/域3）。
- **from-default-profile**：未对齐（EEXIST 拒绝而非替换，域3）。
- **web-listener-trust-config / operator-connect / account 系 / desktop-test-auth-popup**：webRuntime→webStartup 与通配拒绝已随早期批吸收（本轮未单独证伪；operator-connect 未对齐随 A5；account 系不适用；desktop-test-auth-popup 自有替代）。
- **账号栈/品牌类**（account-sign-in-errors、deepseek-account-*、account-notification-fields）：不适用，自有 accounts-local/ui-account 替代。
- 结论：**dsh 第三方插件的启动兼容面成立**（rescope 名字经 dsh-compat aliases/home-paths upstream-named 导出承接），唯 engines.dsh 为 advisory 的裁决使「拒绝不兼容 dsh 插件」的保护缺位——由 allow-version 人工豁免补位。
