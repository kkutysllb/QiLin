## 3. 引擎功能与内核差异总结（vs QiLin 当前）

QiLin（rc.1 对齐）与上游 rc.2 的内核差异 = 六处实质变更：
1. **llm 目录/兼容矩阵**：pi-ai 0.87.1（旧模型 ID 移除、Mistral API、replay 签名语义）——QiLin 完全未含；
2. **交互内核**：timed questions 双结算架构（waterfall 前台 + steer 迟到 + inbox 持久化排队）+ `user-question-reply` 持久化扩展——QiLin 完全未含；
3. **插件运行时检查**：inspect fail-fast + 超时配置——QiLin 未含；
4. **api/gateway**：`hasLiveClient()` 接口——QiLin 未含（若 QiLin fork 了 gateway 实现需补）；
5. **执行层确定性修复**：pwsh END 正则、shell 列表去重、工具提示加固、Windows ACL 单跑——QiLin 均为旧实现（bug 原样存在）;
6. **schedule framing**：提醒框架行语义变化——QiLin 未含。
其余内核（agent-loop/compaction/context/session/vendor/native/python）**零差异**。会话格式与 SQLite schema 稳定，仅 catalog SHA 层面有同版本扩展。
