## 2. 真实残留（本计划要对齐的面）

### D1 credential-hint 数据流与文案簇（7110b615eb + 5249d9a4 的 ui 半边 + b967475c66 hooks）

上游 rc.2 的 ProviderEditor.tsx 与麒麟分叉 151 行（diff 计数），实质是提示数据流不同：

- 上游：提示所需状态全部来自页面快照——ProviderRow 携带 defaultBaseURL?、credential: CredentialInfo | undefined（named 引用脱敏态）、credentialChecks?；ProviderEditor 以 props 接收，不自行发 describe。
- 麒麟：ProviderEditor 组件内部 operations.describeCredential(keyRef) 按需拉取 keyState（useEffect + stale guard），只在挂载/输入变化时刷新。
- 上游另有远程访问 hooks：onSubmitCredential?（凭据表单提交前回调）与 onBusyChange?（apply/endpoint-interrogate in-flight 上抛，配 listBusy 态）；消费方在 remote access 客户端面（麒麟 packages/api/remote-access 已存在，未消费这两个 props）。
- 上游还有 credential-only 编辑模式：credentialOnly?（只渲染凭据字段与动作）、credentialRequired?（提交前必须输入新凭据）、凭据字段 autofocus——DeepSeek 引导弹窗复用同一编辑器。
- locales 键位差：上游独有 keyPlaceholderFallback/keyHelp（Saved credentials are used first. Environment fallbacks … in order: {env}. Sources are launch environment, $cwd/.env, then $DSH_HOME/.env.）/authHelp/baseUrlPlaceholder/customAnthropicBaseUrlPlaceholder/baseUrlDefault: 'No default endpoint'；麒麟独有 keyPlaceholderNative/keyStored/keyEnvLocked/baseUrlDefault: 'Provider default'/customAdd/customTitle。
- README 双语随代码分叉：上游描述 nativeAuth 目录提示优先级（忽略含 oauth 的引用、native-only 路由整段隐藏密钥字段、nativeAuth 变量排除 baseURLEnv）；麒麟 README 仍是 describe 三态旧描述。
- 麒麟有意保留的差异（不改）：add/provider 等「提供方」措辞、advancedHint 的 settings.yaml 指称、customAdd/customTitle 自有新增流文案、deepseek-account 集群整体省略（见 §3 红线）。

### D2 store.ts 错误处理 fail-loud（一行）

上游 load()：if (mirrored.error === null) throw new Error('settings describe settled with neither a view nor an error')（v8 ignore 注释）后 this.failLoad(mirrored.error)；麒麟合并为 this.failLoad(mirrored.error ?? 'settings are unavailable in this browser')，把「不可能状态」静默兜底。按「Misconfiguration fails loud」应对齐上游。

### D3 headless 凭据隔离（5249d9a4ce，PR #5483）——需拍板

上游：bundle/base/cordis.patch.yml authorization 段改为「managed .credentials.yaml 优先，env/.env 兜底」；bundle/headless/cordis.patch.yml 显式禁用 credentials/authorization 账号面挂载——headless 只用 env 与 .env，不读已保存密钥；新增 profiles/headless/tests/credentials.e2e.ts（203 行）与 agent note 2026-10-12-headless-environment-auth 三语。麒麟 packages/bundle/headless/cordis.patch.yml 无禁用行，headless 继承凭据存储、仍读已保存密钥（alpha.5 delta 判「未对齐（中，安全相关）」仍有效）。行为变化：对齐后麒麟 headless 将无法使用已保存密钥。

### D4 credentialOnboarding host flag（onboarding-config.ts 簇）——需拍板

上游 src/onboarding-config.ts + index.ts 条件注册：Host 经 webserver/index-inject 发布 credentialOnboarding（默认 true），Client 注册引导弹窗前校验；Electron preload 标记同时抑制自动凭据引导与 Web 欢迎须知。麒麟无该 flag（全仓零命中），DeepSeek 引导弹窗无条件按状态注册；welcome notice 麒麟已整体删除（有意）。该簇上游归属「native welcome window」提交，与麒麟桌面壳边界决策（不移植 deepseek-account/welcome 栈）纠缠。
