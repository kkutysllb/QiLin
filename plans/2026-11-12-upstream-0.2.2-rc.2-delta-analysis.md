## 2. 区间证据与发布说明的归属

- rc.1 的树 = alpha.3 的树 + 两个版本提交（见 `plans/2026-11-05-upstream-0.2.2-rc.1-delta-analysis.md` §2）。因此**不要把 rc.2 的 76 条发布说明当成 rc.1 的新增**：它覆盖 `v0.2.1-rc.5 → rc.2`（发布说明自述窗口），其中 alpha.2/alpha.3 部分已由 `plans/2026-10-28-…alpha.2-delta-analysis.md`、`plans/2026-11-03-…alpha.3-delta-analysis.md` 消化。本文只对**尚未吸收的条目**给出处置，已落地项标注指针。
- 发布说明条目数（中文正文，逐条镜像英文）：新增功能 3、体验优化 27、问题修复 26、其他变更 20，合计 76 条。
- 升级指南 19 篇是**破坏性变更的权威清单**，比发布说明的「其他变更」20 条更细：`account-notification-fields`、`account-remote-provider`、`archive-worktrees`、`attachment-error-codes`、`cua-ax-read-limits`、`cua-hover-ax-only`、`cua-native-platform`、`dsh-doc-skill`、`forge-change-request-overview`、`forge-pinned-diff`、`forge-review-reads`、`plugin-update-method`、`runtime-context-reminders`、`session-append-overloads`、`subagent-interrupt-default`、`terminal-backend-cleanup-error`、`terminal-bundle-sidebar-backend`、`web-search-billing`、`window-drag-regions`。
- 本区间形成三处「包族搬家」：agent-team 四包 `experimental/ → team/`（服务端）与 `client/ui-agent-team`；Office 两包（`office-to-pdf → office-kit`、新增 `tool-office`）；账户通知从 `ui-settings-account` 拆出 `ui-account-notifications`。搬家在 QiLin 是**包名与 manifest 变更**，不是目录移动，必须走 B6/B7 专项。

## 10. 与 3.1.11 的关系、优先级

- 3.1.11 已发布，本区间对齐落在 3.2.0（feat/minor）或 3.1.12（仅修复）之间；建议 **3.2.0**，因为 B1/B2 引入引擎新能力与错误语义变化。
- 优先级：**B1（本次已做）→ B2 引擎契约 → B3 web 搜索 → B4/B5 客户端快赢 → B8 终端/MCP → B6/B7/B9/B10 大专项**。
- 引擎面优先的理由：B2 的 session/tools/错误码是后续所有批次的公共依赖；先落它可避免每个客户端批次各写一份兼容层。
- 字体默认变更不是上游对齐项，随本批一起交付（见对齐计划 §8）。

## 12. 取材与方法

- 区间统计：`git diff --numstat dsh-v0.2.2-rc.1 dsh-v0.2.2-rc.2`、`git rev-list --count`、`git ls-tree -r`。
- 发布说明：`gh release view dsh-v0.2.2-rc.2 --json tagName,publishedAt,body`，正文落盘后按 `###` 分节计数。
- 破坏性变更：`git ls-tree -r --name-only dsh-v0.2.2-rc.2 docs/upgrade-guide/v0.2.2-rc.1` 逐篇读 `guide.md`。
- 代码落点：`git log --no-merges dsh-v0.2.2-rc.1..dsh-v0.2.2-rc.2 -- <pkg>` 与 `git show` 具体提交，按提交主题检索（UA profile 后缀、pi-ai 前导状态归类、app-boot 端点接受、session 批量追加）。
- QiLin 现状：`grep`/`ls` 本树对应包与符号；未逐行比对的条目在表中标 `[推断]`。
- 未核对项（明确登记）：Anthropic 签名 thinking 省略是否已在 QiLin 的 replay 面等价实现；Gemini 原生 provider；Safari 文字放大；停止/关会话资源顺序；可选插件失败不阻断启动。这些在开工前用「读源码 + 最小复现」补证，不按发布说明直接改。
